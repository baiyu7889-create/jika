# 基咔 H5 / App MVP 前端原型

打开 `index.html` 即可体验产品原型，无需安装依赖或启动服务。桌面端以 iPhone 15 Pro 评审壳展示；手机浏览器自动切换为全屏 H5，并适配底部安全区。底部固定为短视频、长视频、AI专区、社区、我的：短视频直接进入类似抖音的黑底竖滑单视频流；长视频采用参考图的蓝色渐变搜索头、横向一级 Tab、六列广告矩阵、关注大卡流、推荐/独家分区流、发现精彩类目页和双列长视频列表。`landing.html` 是文档要求的 1920×1080 暗黑暖金下载落地页。

运营评审请直接打开单文件 `operations-prototype.html`：该入口只显示可操作的纯 H5 原型，不展示设备外壳、项目标题或开发说明，文件内包含当前 rc33 的样式、演示数据和已实现交互，可脱离项目目录单独发送。它用于评审，不代表真实支付、治理、推送或后台任务已经联调。

## MVP 1.0 对齐范围

- 冷启动：首次年龄确认后展示资源加载页和 5 秒可横滑启动广告；倒计时结束后必须手动点击“跳过”进入短视频。短视频不展示营销广告弹窗；平台公告按系统通知独立配置。用户首次主动进入长视频时，再顺序展示最多 6 个方形广告，同一会话不重复。
- 首次进入：18 岁确认、协议与隐私入口。
- 五大入口：短视频、长视频、AI专区、社区、我的；参考截图中的首页/片库/社区/暗网仅作框架参考，按 PDF 注释完成正式标签替换。
- 内容闭环：封面/详情/播放器，加载、播放/暂停、进度、倍速、静音、清晰度、线路、全屏、试看蒙层、支付后原位续播。
- 视频详情：VIP/金币双类卡标、播放次数、播放器下全站四行广告、作者个人主页，双列“为你推荐”最多 6 条，评论位于推荐下方。
- 资产闭环：独立会员页采用“上方横滑会员卡、下方付款方案”，当前卡居中并露出相邻卡；MVP 1.0仅展示基础VIP年卡、限时狂欢卡、AI专区年卡和年度全站通卡四个固定商品，同时保留金币钱包、充值包、退款申请与结果状态。
- 全局搜索：短视频与长视频共用同一独立搜索页，初始页展示共享搜索历史、热搜总榜和热门标签，搜索后支持全部/视频/合集/帖子/用户/标签结果与来源返回。
- 标签与合集：标签结果进入独立聚合页；合集展示总集数、更新数、逐集名称、购买与进度，支持整套解锁后回原集续播。
- AI 闭环：四类基础工具均进入独立二级页，三行固定+一行轮播广告、素材预检/小说配置、授权确认、资产冻结、失败/超时/安全校验未通过、成功通知、结果查看与重新生成。
- 社区闭环：交流区包含推荐、最新、热门、求片和关注；求片支持想看、运营关联已上架内容、已解决状态与参与者通知。保留资源分区、统一四行广告、右下角悬浮发布、独立详情、大图/视频查看、楼中楼评论和举报/拉黑；帖子不支持收费或外链直达。
- 短视频：底栏直接进入竖滑单视频流，默认自动播放，点击画面暂停并在中央显示播放键；右侧按 PDF 保留头像、点赞、评论、收藏、分享和举报，并保留运营确认的清屏。VIP Demo试看统一为5秒；到时后在播放器内展示付费蒙层，不使用底部弹层，蒙层可进入会员/金币充值并允许继续上滑切换下一条。
- 长视频聚合首页：八个一级 Tab 全部展示同一套广告区，最多四行，前三行固定六列、第四行自动轮播；关注为大卡流，推荐/独家为分区双列流，分类型页下方为发现精彩、全部类目页和双列分类视频列表；列表作者可独立进入默认“视频”Tab 的个人页。
- 账户闭环：钱包、订单、已购/收藏/观看记录、消息、客服、设置、设备、注销和我的帖子均为独立业务页；设置新增 App 图标选择页，内置五种日常样式并明确 H5 仅演示、App 才能调用系统切换能力。
- 公开个人页：视频/帖子独立 Tab 与范围搜索；视频作者入口默认视频，社区作者入口默认帖子；帖子 Tab 使用独立作者卡片流（作者、时间、正文/媒体、互动数据与话题），不改变社区信息流或帖子详情；查询结果进入同一内容 ID 详情，返回保留搜索上下文。
- 多级返回：首页、视频详情、作者个人页和作者作品详情采用逐级页面栈；返回同步恢复内容 ID、播放器、Tab、筛选、搜索词和滚动位置。

## H5 与 App 共用 / 差异

共用信息架构、业务组件、权益校验和服务端订单结果。App 形态保留系统状态栏、设备安全区与底部 Home Indicator；H5 在窄屏下移除设备壳和模拟状态栏，以真实浏览器视口全屏运行。

## 已实现的逻辑护栏

- 会员标准内容与金币精品内容使用互斥付费墙，播放器同步展示正确权益类型。
- MVP 1.0仅展示基础VIP年卡、限时狂欢卡、AI专区年卡和年度全站通卡；不展示体验卡、月卡、季卡和终身卡。
- 精品内容按“精品券 -> 活动币 -> 付费金币”扣减；AI按“AI额度 -> 活动币 -> 付费金币”预冻结，失败、超时或未通过时按来源原路退回。
- 精品券“一张抵一笔订单”仅为可回退的演示默认值，结算页已显式提示，正式面值与范围仍待产品、财务确认。
- 支付回调按业务单号幂等发放，重复查询不会重复增加权益或扣减资产。
- 金币不足时记录恢复意图；充值成功自动回到原内容或合集，重新校验价格后继续解锁。
- 同卡会员顺延，不同卡并存；AI年卡和全站通卡只发当前30日周期资产，限时狂欢卡执行三重限购。
- 成功订单可在详情中申请退款；原型可演示服务端处理完成/拒绝，并同步冲正未消费权益，生产环境客户端无审批权限。处理中、失败和关闭订单可带业务单号创建补单核查工单。
- 首充额外奖励与充值包普通赠送分开计算；首笔支付成功时按服务端资格只发放一次，并以同一业务单号记录流水。
- AI 成功后扣除冻结资产；失败或安全校验未通过按原资产组成逐项退回。
- 搜索词与社区标题经过输出转义；社区内容提交时执行敏感词即时校验，命中失败并保留草稿；新账号或含媒体帖子先显示处理中，通过后再进入公开信息流。
- 频道、筛选和分段按钮均提供选中状态或明确反馈；MVP 1.1 功能不展示入口、预留卡或“即将开放”占位。
- 长视频播放器的加载、播放/暂停、可拖动进度、清晰度、线路、倍速、静音和全屏均有可见状态变化；播放时钟按倍速推进，所有切换保留进度。

## 冻结前待决策

PRD 已将 AI 脱衣合规与渠道边界、精品券面值、会员升级/赠送去重、退款资格与 SLA、支付渠道和设备限制列为 `O-01` 至 `O-07`。这些项目仍需产品、法务、财务、风控与技术联合关闭；原型中的演示值不等于正式业务承诺。

## 暂不纳入一期

直播、下载、投屏、打赏、粉丝团、创作者分成/提现、签到、邀请、会员日、离线缓存、多级代理与复杂 DMP 均未进入原型主流程。

## 建议评审路径

1. 完成 18 岁确认。
2. 在会员中心检查基础VIP年卡、限时狂欢卡、AI专区年卡和年度全站通卡四张P0卡；购买 AI 卡后回到短视频，验证其不会解锁视频内容。
3. 在短视频点击“试看已结束”，验证标准内容只出现含视频权益的付费墙，并完成登录、建单、支付、查单与原位恢复。
4. 完成启动广告后进入短视频，确认没有营销广告弹窗；平台公告按独立开关展示。首次点击底部长视频后验证最多 6 个方形广告依次出现，关闭完成后再次进入长视频不重复。
5. 验证首条 VIP 短视频自动展示一次“试看已结束”会员引导；关闭后不自动重复，主动点击可重开，进入会员中心再返回仍保留当前视频。
6. 切换长视频，打开会员内容与金币精品，验证两类权益互斥、试看蒙层与原位续播，再验证播放器全部控件、视频评论和六条推荐。
7. 分别从短视频作者、视频详情作者和视频列表作者进入公开个人主页，检查默认“视频”Tab、资料、粉丝/获赞/关注/作品数和双列作品。
8. 直接切换底部 AI专区，提交任务并逐步推进状态，或模拟失败验证冻结资产原路退回；长视频广告矩阵中的“AI创作”也可切换到同一模块。
9. 切换社区，从右下角悬浮入口进入独立发布页，选话题、填标题/正文并添加图片/视频；确认无价格字段；命中敏感词时直接失败并保留草稿，修改后直接发布成功。
10. 进入帖子详情，验证完整图文/视频、评论、收藏、举报和拉黑；列表、编辑页和详情均不得出现收费帖或解锁入口。
11. 切换我的，进入成功订单申请退款，分别验证退款中、通过/拒绝结果及资产同步。
12. 从“我的—金币充值”选择任一档位，检查普通赠送和首次充值额外奖励分别展示；完成首笔回调后再次进入充值页，首充提示应消失。
13. 打开失败或关闭订单，点击“提交补单核查”，确认客服页自动带入“补单申请”、业务单号和问题描述，创建后只生成工单而不直接增加资产。
